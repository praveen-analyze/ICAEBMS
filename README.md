# ICAEBMS 2026 — Premium Conference Homepage

A React + Vite + Tailwind + GSAP conference homepage inspired by the professional information architecture of international conference sites such as Confworld, with an original editorial visual direction.

## Run

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```

## Notes

- Conference content follows the supplied Test Round 1 document.
- The visual assets in `public/images` are local SVG artwork, so the page does not depend on external image hosts.
- Replace the local artwork with approved conference photography/logos when official assets are available.
